🩺 About AI Disease Prediction System

AI Disease Prediction System is a Machine Learning based healthcare application that analyzes user symptoms and predicts possible diseases.

Key Features

  • AI based disease prediction
  • Confidence score analysis
  • Top 3 disease suggestions
  • Emergency risk alert
  • Doctor recommendation
  • PDF medical report generation

Technology Used

  • Python
  • Flask
  • Machine Learning
  • HTML, CSS, Bootstrap
  • Scikit-Learn
